# API Automation - Rest Assured Java

REST API test automation framework built with Java, Rest Assured, TestNG, and Maven. Validates CRUD operations on REST APIs with clean architecture and CI integration.

## 🚀 Tech Stack
- **Java 17** - Programming language
- **Rest Assured 5.4.0** - API testing library
- **TestNG 7.9.0** - Test framework
- **Maven** - Build and dependency management
- **Lombok** - Reduces boilerplate in POJOs
- **Owner** - Type-safe config properties
- **GitHub Actions** - CI/CD pipeline
